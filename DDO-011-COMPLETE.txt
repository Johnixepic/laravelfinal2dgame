Task: Phaser Runtime Repair — fix 'Cannot read properties of undefined (reading "dims")' error.

STATUS: ALL TASKS COMPLETED

Root Cause:
The create() method was defined as:
    create(startMapId = 'MAP1', startTile = null) {

In Phaser 4, when this.scene.start('WorldScene', { startMapId: mapId }) is called,
the data object is passed as this.data on the scene instance — NOT as positional
function parameters to create(). This means startMapId was always undefined,
MAPS[undefined] returned undefined, and undefined.dims threw the TypeError.

Fix Applied:
    create() {
        const startMapId = this.data?.startMapId || 'MAP1';
        const startTile = this.data?.startTile || null;
        const mapDef = MAPS[startMapId];
        // ... rest unchanged
    }
