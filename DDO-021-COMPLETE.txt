## Game Overview
- **Title**: THE LAST CONNECTION
- **Genre**: 2D exploration/crafting game (Phaser.js)
- **Canvas**: 960×600, responsive resize
- **Maps**: 5 connected maps (island chain, eastward progression)
- **Win Condition**: Build a boat through 4 stages, reach the coast, sail away

## Controls
| Key | Action |
|-----|--------|
| WASD / Arrows | Move |
| E | Interact (search, gather, craft, build boat) |
| ESC | Close crafting panel |
| R (after win) | Restart game |

## Demonstration Script
1. Start game — player appears on Home Island
2. Search "Your Home" (E) — get wood, cloth, food
3. Walk to workbench (E) — open crafting panel
4. Craft Crude Axe (if resources available)
5. Cut trees for wood (E near trees)
6. Walk to Boat Dock (south) — build Hull stage
7. Explore east to MAP2 — search houses for scrap
8. Return to boat — build Reinforcement stage
9. Continue to MAP3 — gather rope from houses
10. Build Rigging stage at boat
11. Continue to MAP4 — gather cloth
12. Build Sail stage — boat complete!
13. Walk all the way to MAP5 — find coast
14. Press E at boat site — cinematic ending plays
15. Press R — game restarts fresh

## Known Limitations (Non-Blocking)
