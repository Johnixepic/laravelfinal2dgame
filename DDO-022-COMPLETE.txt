## Changes Made

### 1. Workbench Discovery Gating (CRITICAL)
**Problem**: Workbenches existed as outdoor obstacles on ALL maps (MAP1-MAP5), bypassing the intended progression gate.

**Fix**:
- Removed all outdoor workbenches from MAP_OBSTACLES (MAP1, MAP2, MAP3, MAP4, MAP5)
- Added `indoorHouses` array to MAP2 definition with `Old Store` at {i:18,j:8} as the designated discovery house
- Implemented `enterIndoorMode()` and `exitIndoor()` methods on WorldScene
- Indoor mode creates a 5×4 grid with floor tiles, walls, door, and workbench
- Player moves via WASD/Arrows inside the indoor grid; E discovers the workbench
- `workbenchDiscovered` flag is now persisted in `GameState` (cross-map) and reset in `restartGame()`

### 2. Boat Construction Location (CRITICAL)
**Problem**: MAP1 had a boatSite at {i:14,j:23}, allowing early boat construction.

**Fix**:
- Removed `boatSite` from MAP1 entirely
- Moved MAP5 boatSite to {i:26,j:27} — southeastern shoreline of the 30×30 grid
- `checkWinCondition()` now explicitly requires `this.currentMapId === 'MAP5'`

### 3. GameState Persistence (HIGH)
**Problem**: `workbenchDiscovered` was scene-local; map transitions reset it.

**Fix**:
- Added `workbenchDiscovered: false` to the `GameState` object
- `transitionToMap()` now syncs `GameState.workbenchDiscovered = this.workbenchDiscovered`
- `create()` reads `this.workbenchDiscovered = GameState.workbenchDiscovered || false`
- `restartGame()` resets `GameState.workbenchDiscovered = false`

### 4. Indoor Exploration Mechanic (CRITICAL)
**Problem**: DDO-013 claimed indoor houses were added, but none existed in the code.

**Fix**:
- Added `indoor_floor` and `indoor_wall` textures in `createTextures()`
- `enterIndoorMode(buildingName, buildingDef)` creates a container-based indoor scene:
  - 5×4 grid of floor tiles (32px each)
  - Border walls (dark brown)
  - Workbench rectangle at designated tile
  - Player sprite (light skin tone) at door position
  - Door indicator at bottom center
- `exitIndoor()` destroys indoor elements and restores outdoor visibility
- Indoor prompt updates contextually: "E — Discover workbench" when near workbench, "Press ESC to exit" when discovered

### 5. Map Progression Gating
**Verified flow**:
1. Start on MAP1 (Home Island) — no workbench, no boat site
2. Search houses on MAP1 for initial supplies (wood, cloth, food)
3. Travel east → MAP2 (Abandoned Settlement)
4. Enter Old Store (indoor: true) → discover workbench inside
5. Workbench discovery unlocks crafting across all maps
6. Continue east through MAP3, MAP4
7. Arrive on MAP5 (Coastal Escape) at {i:26,j:27}
8. Build boat at MAP5 boat site (all 4 stages)
9. Press E at boat site → cinematic ending

### 6. Victory/Restart Logic (Verified)
- `checkWinCondition()`: boatBuilt=true AND currentMapId='MAP5' AND near boatSite
- `showEnding()`: black fade → staggered text overlay → "Press R to play again"
- `restartGame()`: full GameState reset + scene.restart()
